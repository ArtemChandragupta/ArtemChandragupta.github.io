# Введение

Не все виртуальные машины одинаковые, некоторые

# Начальные требования

Перед началом нужно:

1) Установить KVM, Libvirt;
2) Установить Qemu;
3) Скачать образ диска с VirtIO драйверами;
4) Скачать образ диска с Windows;

# Создание виртуальной машины

1) Зайти в меню настроек Virtual Machine Manager и включить редактирование XML - это нужно для последующих манипуляций.

![fig1](/images/VM/VM-1.png)
*Настройки VMM*

![fig2](/images/VM/VM-2.png)
*Включено редактирование XML*

2) Нажать на кнопку создания новой виртуальной машины и проделать очевидные шаги настройки до меню с выбором имени, где следует активировать кастомизацию перед установкой и нажать Finish. После этого откроется окно кастомизации.

![fig3](/images/VM/VM-3.png)
*Окно выбора имени VM*

3) В пункте Overview проверить, что стоит чипсет Q35

![fig4](/images/VM/VM-4.png)
*Чипсет Q35*

4) В пункте CPUs проверить, что включен проброс ядер процессора.

![fig5](/images/VM/VM-5.png)
*Проброс ядер процессора*

5) В пункте SATA Disk 1 необходимо изменить шину с SATA на VirtIO, специально оптимизированную для виртуальных машин. Это чрезвычайно важный пункт для быстродействия машны. Так как кеш нам не нужен, его тоже лучше отключить.

![fig6](/images/VM/VM-6.png)
*Настройка хранилища*

6) Монтирование образа диска с VirtIO драйверами. Внизу списка устройств находится кнопка Add Hardware, во всплывающем окне выбираем Storage, в пункте Select or create custom storage выбираем образ диска VirtIO драйверов. Тип устройства выбираем как CDROM.

![fig7](/images/VM/VM-7.png)
*Монтирование диска с драйверами*

7) В пункте NIC (Network Interface Controller) выбираем тип устройства VirtIO.

![fig8](/images/VM/VM-8.png)
*Настройка сети*

8) Устройство Tablet можно удалить.

Таким образом, подготовка к установки гостевой ОС завершена.
